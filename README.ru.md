[English](https://github.com/ilyshkafox/dsh-a2a-client/blob/main/README.md) | **Русский** | [中文](https://github.com/ilyshkafox/dsh-a2a-client/blob/main/README.zh.md)

Клиент [Agent2Agent (A2A) 1.0](https://a2a-protocol.org) для DeepSeek Harness.
Подключает удалённых агентов к вашей модели и добавляет панель **A2A**, где они
добавляются, проверяются и удаляются без правки файлов.

Модель получает три инструмента — посмотреть карточки агентов, отправить
сообщение, поработать с задачами. Вы получаете панель в сайдбаре; зависимостей
нет, только встроенные `fetch` и `node:crypto`.

Транспорт — JSON-RPC 2.0 поверх HTTP с заголовком `a2a-version: 1.0` и
необязательным `authorization: Bearer`; методы `SendMessage`,
`SendStreamingMessage` (SSE), `GetTask`, `CancelTask`, `ListTasks`. Карточки
агентов кэшируются на 30 секунд.

## Установка

Пакет называется `dsh-a2a-client`. Установка сразу включает бандл: `dsh plugin add`
добавляет зависимость профиля и запись в `dsh.profile.bundles`.

### Профиль web

```sh
dsh plugin --profile web add dsh-a2a-client                      # из npm
dsh plugin --profile web add github:ilyshkafox/dsh-a2a-client    # из git
```

Перезапустите DSH: панель **A2A** появится в сайдбаре, инструменты — в чате.

### Desktop

Профилем Desktop владеет приложение: запустите его один раз, чтобы профиль
появился, закройте и выполните команду `dsh`, которая поставляется вместе с
приложением — и блокировка профиля, и загруженный бандл принадлежат работающему
приложению.

```sh
dsh plugin --profile desktop add dsh-a2a-client
```

Затем запустите приложение снова. Отдельно установленный из npm `dsh` профиль
`desktop` не примет: управлять им может только команда самого приложения.

### Панель «Плагины»

**Плагины** → установить, цель `dsh-a2a-client` (npm) или
`github:ilyshkafox/dsh-a2a-client` (git). Панель проверит репозиторий и версию
DSH, покажет прогресс и сообщит, нужен ли перезапуск.

### Вручную

Добавьте обе записи в `package.json` профиля (`~/.dsh/profiles/web/package.json`)
и выполните `pnpm install`:

```json
{
  "dependencies": { "dsh-a2a-client": "github:ilyshkafox/dsh-a2a-client" },
  "dsh": { "profile": { "bundles": ["@deepseek-ai/dsh-base", "@deepseek-ai/dsh-web-app", "dsh-a2a-client"] } }
}
```

Для локального каталога — `"dsh-a2a-client": "link:/абсолютный/путь/к/dsh-a2a-client"`.

### Первый агент

Откройте **A2A** → **Добавить агента**: имя, адрес AgentCard и токен, если он
нужен. Карточка читается сразу, поэтому неверный адрес или токен не сохранится.

Git-установка, зафиксированная на полный 40-символьный коммит, обновляется
кнопкой **Обновить** в панели; ветку или тег нужно переустанавливать.

## Настройка

Агенты живут в реестре профиля `a2a-client.json`, его наполняет панель. Пока
файла нет, агенты берутся из `config` плагина:

```yaml
config:
  defaultAgent: my-agent        # агент по умолчанию для a2a_send и a2a_task
  tokenEnv: A2A_AUTH_TOKEN      # общая ссылка на секрет (необязательно)
  timeoutMs: 180000             # один HTTP-вызов
  agents:
    - name: my-agent
      cardUrl: https://agent.example.com/.well-known/agent-card.json
      tokenEnv: A2A_TOKEN_MY_AGENT
      timeoutMs: 120000
```

| Поле | По умолчанию | Назначение |
| --- | --- | --- |
| `name` | — | Имя агента для инструментов: до 64 символов, буквы, цифры, пробел, `_`, `.`, `-` |
| `cardUrl` | — | Абсолютный `http://` или `https://` адрес AgentCard |
| `tokenEnv` | `A2A_TOKEN_<ИМЯ>` | Ссылка на секрет: переменная окружения или запись в хранилище DSH |
| `token` | пусто | Токен прямо в конфиге; уступает хранилищу и окружению |
| `timeoutMs` | `180000` | Таймаут одного HTTP-вызова к этому агенту |
| `enabled` | `true` | Выключенный агент виден в панели, но не опрашивается |
| `allowCrossOriginToken` | `false` | Разрешить отправку токена на JSON-RPC endpoint другого origin, чем у карточки |

### Токены

У каждого агента свой секрет. Имя ссылки выводится из имени агента:
`A2A_TOKEN_<ИМЯ>` в верхнем регистре, где всё кроме латинских букв и цифр
заменено на `_` — `prod agent` даёт `A2A_TOKEN_PROD_AGENT`.

Токен, введённый в панели, попадает в **хранилище секретов DSH**
(`ctx.credentials`, файл `~/.dsh/.credentials.yaml`), а не в `a2a-client.json`.
Порядок поиска:

1. Хранилище секретов DSH — то, что сохранено в панели.
2. Переменная окружения процесса и `.env`.
3. Поле `token` в конфиге или в `a2a-client.json` — только чтение, для записей,
   сделанных до перехода на хранилище.

## Инструменты

| Инструмент | Параметры | Назначение |
| --- | --- | --- |
| `a2a_agents` | `agent?`, `refresh?` | Список агентов: имя, карточка, умения, интерфейсы |
| `a2a_send` | `text` (обязателен), `agent?`, `contextId?`, `stream?`, `timeoutSec?` | Отправить сообщение и вернуть финальный ответ |
| `a2a_task` | `action` (обязателен: `get`, `cancel`, `list`), `taskId?`, `agent?`, `contextId?` | Прочитать, отменить или перечислить задачи |

`a2a_send` продолжает диалог через `contextId`: он возвращается в ответе и
запоминается для пары «сессия + агент», поэтому следующий вызов обходится без
ручного контекста.

## Панель

**A2A** в сайдбаре показывает агентов карточками: имя, состояние подключения,
описание из карточки и адрес. В окне агента — метаданные, сама карточка, список
умений и тестовое сообщение; рядом добавление, правка и удаление.

Агенты бывают двух уровней: общие для профиля и локальные для рабочей области
(`<workspace>/.dsh/a2a-client.json`). Изменения из панели сохраняются сразу и
переживают перезапуск. Язык панели следует за DSH — русский, английский или
китайский, переключается в **Настройки → Основные → Язык** без перезапуска.

## Безопасность

- Маршрут панели `/a2a-client/api` защищён штатной проверкой DSH
  `ctx.connection.requestRejection`: Host и Origin против DNS-rebinding плюс
  аутентификация браузерной сессии.
- Loopback-имя принимается только как литерал `127/8`, `localhost` или `::1`;
  имя вида `127.evil.com` отклоняется.
- Токен не уходит на другой origin, чем карточка, и не уходит по открытому
  `http://` на удалённый хост; смена `cardUrl` требует своего токена.
- Карточка читается только по same-origin редиректам; JSON-RPC POST — ни по
  каким.
- Ответы карточки, JSON-RPC и SSE ограничены 1 / 4 / 8 МБ.
- Вывод агента обёрнут границами `--- внешние данные A2A-агента ---`: это
  данные, а не инструкции. Относитесь к нему как к недоверенному тексту.

## Разработка

Зависимостей и сборки нет. Правки `client.js` подхватываются перезагрузкой
страницы, `index.js` — перезапуском DSH.

```sh
npm test        # наборы locale и security
npm run check   # синтаксис обеих половин
npm publish     # сначала прогоняет check и test (prepublishOnly)
```

`files` в `package.json` — весь состав npm-пакета: `index.js`, `client.js`,
`cordis.patch.yml`, `locale/*.json`, `icon.svg` плюс README и лицензия, которые
npm добавляет сам. Новый файл рантайма нужно добавлять и в `files`, и в
`exports`.
