# @local/dsh-a2a-client

Плагин DeepSeek Harness: клиент протокола **Agent2Agent (A2A) 1.0**.

Подключается к удалённому A2A-агенту по его AgentCard, регистрирует модельные
инструменты для обмена сообщениями и добавляет панель **«Настройки → A2A»**
в левом сайдбаре.

- Ноль зависимостей — только встроенный `fetch` и `node:crypto`.
- Сборка не нужна: браузерную половину грузит загрузчик модулей DSH.
- Токены не покидают host-процесс: в браузер они не отдаются.

## Возможности

| Что | Как |
| --- | --- |
| Карточка агента | `GET <cardUrl>` с кэшем на 30 секунд и ручным обновлением |
| Обмен сообщениями | `SendMessage`, `SendStreamingMessage` (SSE) |
| Работа с задачами | `GetTask`, `CancelTask`, `ListTasks` |
| Транспорт | JSON-RPC 2.0, заголовок `a2a-version: 1.0` |
| Аутентификация | `authorization: Bearer <токен>`, если токен задан |
| Реестр агентов | файл `a2a-client.json` в каталоге профиля, им владеет панель |
| Панель | список агентов карточками, окна просмотра, добавления и правки, проверка связи |

## Инструменты для модели

### `a2a_agents`

Показывает настроенных агентов: имя, карточку, умения и интерфейсы. Стоит
вызывать в начале работы, чтобы понять, кто вообще доступен.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `agent` | `string` | Имя агента. Не указано — все настроенные. |
| `refresh` | `boolean` | Перечитать карточку с сервера, не из кэша. |

### `a2a_send`

Отправляет сообщение удалённому агенту и возвращает его финальный ответ.
Продолжение диалога — тем же `contextId`; он возвращается в ответе и
запоминается автоматически.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `text` | `string` | **Обязателен.** Текст сообщения. |
| `agent` | `string` | Имя настроенного агента; по умолчанию `defaultAgent`. |
| `contextId` | `string` | Контекст прошлой задачи для продолжения диалога. |
| `stream` | `boolean` | Использовать `SendStreamingMessage` (SSE) вместо `SendMessage`. |
| `timeoutSec` | `number` | Таймаут ожидания ответа в секундах. |

### `a2a_task`

| Параметр | Тип | Описание |
| --- | --- | --- |
| `action` | `get` \| `cancel` \| `list` | **Обязателен.** Что сделать с задачами. |
| `taskId` | `string` | Идентификатор задачи для `get` и `cancel`. |
| `agent` | `string` | Имя настроенного агента. |
| `contextId` | `string` | Фильтр по контексту для `list`. |

## Установка

Пакет распространяется как есть: `"private": true`, в npm не публикуется, но
открыт для использования и доработки. Он объявляет себя бандлом:
`dsh.bundle.patch` указывает на `cordis.patch.yml`, а тот вставляет плагин
в профиль под идентификатором `a2a-client`.

1. Склонируйте репозиторий и добавьте каталог пакета в зависимости профиля.
2. Подключите патч-слой — содержимое `cordis.patch.yml`:

```yaml
- insert:
    - id: a2a-client
      name: '@local/dsh-a2a-client'
      config:
        timeoutMs: 120000
```

3. Перезапустите DSH. В сайдбаре появится панель «A2A», в чате — три инструмента.
4. Добавьте агента в панели: имя, `cardUrl` его AgentCard и, если нужно, токен.

Готовых агентов плагин не поставляет — только сам протокол. Это осознанно:
`cardUrl` у каждого свой, а адрес и токен в открытом репозитории были бы
бесполезны и небезопасны.

## Настройка

Конфиг плагина — обычный объект `config` у записи в патч-слое. Агентов можно
задавать и здесь, и в панели; панель пишет в `a2a-client.json` в каталоге
профиля, и такие записи переживают перезапуск.

```yaml
config:
  defaultAgent: my-agent      # агент по умолчанию для a2a_send и a2a_task
  tokenEnv: A2A_AUTH_TOKEN    # имя переменной окружения с токеном (значение по умолчанию)
  timeoutMs: 180000           # таймаут одного HTTP-вызова
  agents:
    - name: my-agent          # имя, по которому агента адресуют инструменты
      cardUrl: https://agent.example.com/.well-known/agent-card.json
      tokenEnv: A2A_AUTH_TOKEN
      timeoutMs: 120000       # переопределяет общий таймаут для этого агента
```

### Токены

`tokenEnv` важнее значения из конфига: сначала читается переменная окружения,
и только потом — поле `token`. Это позволяет держать секрет вне файлов.

- Предпочтительно — переменная окружения: `A2A_AUTH_TOKEN=...`
- Поле `token` в конфиге допустимо, но такой файл нельзя коммитить.
- Локальная копия конфига с настоящим токеном — `cordis.patch.local.yml`,
  он в `.gitignore` и в репозиторий не попадает.

## Структура

```
index.js            host-половина: инструменты, JSON-RPC, SSE, HTTP-маршрут /a2a-client/api
client.js           браузерная половина: панель «A2A» (без сборки)
cordis.patch.yml    патч-слой бандла: вставка плагина в профиль
locale/ru.json      русские подписи панели
locale/en.json      английские подписи панели
icon.svg            иконка плагина
```

## Разработка

```sh
git clone git@github.com:ilyshkafox/dsh-a2a-client.git
cd dsh-a2a-client
```

Зависимостей нет, `npm install` не требуется. Правки `client.js` подхватываются
перезагрузкой страницы; правки `index.js` — перезапуском DSH.

Проверка синтаксиса:

```sh
node --check index.js
node --check client.js
```
